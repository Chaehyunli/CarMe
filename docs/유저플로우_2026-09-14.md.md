# CarMe 차량별 매뉴얼 상담 유저플로우

```mermaid
flowchart TD
  start([앱/웹 진입]) --> loggedIn{로그인 상태?}
  loggedIn -- 아니오 --> login[로그인 화면]
  login --> kakao[카카오 로그인]
  kakao --> authOk{인증·필수 동의 성공?}
  authOk -- 아니오 --> authError[인증 오류/재시도 안내]
  authError --> login
  authOk -- 예 --> home[홈]
  loggedIn -- 예 --> home

  home --> hasVehicle{등록 차량이 있는가?}
  hasVehicle -- 아니오 --> register[차량 등록]
  register --> selectVariant[차량 모델·연식·필요한 모델 구분 선택\n별칭 입력]
  selectVariant --> manualReady{적용 매뉴얼이 READY인가?}
  manualReady -- 아니오 --> unavailable[현재 상담을 준비 중입니다]
  unavailable --> home
  manualReady -- 예 --> vehicleList[내 차량 목록]
  hasVehicle -- 예 --> vehicleList
  vehicleList --> vehicleDetail[차량 상세\n별칭 수정 또는 삭제]
  vehicleList --> consultHome[상담 시작]
  vehicleList --> historyList[차량별 상담 이력]

  consultHome --> selectVehicle[등록 차량 선택]
  selectVehicle --> conversation[상담 세션]
  conversation --> question[카테고리·세부 증상 선택\n또는 자연어 질문 입력]
  question --> safety{위험 신호인가?}

  safety -- 예 --> safetyEscalation[즉시 안전 안내\n공식 지원 경로]
  safetyEscalation --> historySaved[질문·전환 결과 저장]

  safety -- 아니오 --> clarity{정보가 충분한가?}
  clarity -- 아니오 --> clarify[추가 질문 표시]
  clarify --> conversation
  clarity -- 예 --> retrieve[선택 차량에 적용되는 매뉴얼만 검색·재정렬]
  retrieve --> evidence{근거가 충분한가?}
  evidence -- 아니오 --> insufficient[매뉴얼에서 확인하지 못함\n상담 전환 안내]
  insufficient --> historySaved
  evidence -- 예 --> grounded[근거 기반 답변 생성]
  grounded --> citation[근거 카드\n문서명·PDF 페이지·본문 쪽수·원문 스니펫]
  citation --> source[원문 보기\npresigned URL로 private PDF 열기]
  citation --> resolved{문제가 해결됐는가?}
  resolved -- 추가 질문 --> conversation
  resolved -- 아니오 --> support[상담 전환 안내]
  support --> historySaved
  resolved -- 예 --> historySaved

  historyList --> historyDetail[상담 이력 상세\n질문·상태·답변·근거 카드]
```

## 화면·상태 규칙

| 화면/상태 | 반드시 표시할 것 | 금지할 것 |
|---|---|---|
| 차량 등록 | 적재·검수된 모델·연식·모델 구분 선택, 별칭 입력 | 세부 옵션·트림 입력 요구 또는 실제 장착 여부 확정 표시 |
| 질문 입력 | 자유 텍스트, 카테고리, 차량 선택 상태 | 차량을 고르지 않은 상담 시작 |
| `AMBIGUOUS` | 한 번에 하나의 짧은 추가 질문 | 근거 없는 조치 안내 |
| `GROUNDED` | 답변, 각 근거 카드, 통합 매뉴얼·옵션 미판정 고지, 해결 여부 | 인용 없는 행동 지시 |
| `INSUFFICIENT_EVIDENCE` | 확인 불가 문구, 상담 전환 수단 | 그럴듯한 원인·해결책 생성 |
| `SAFETY_ESCALATION` | 일반 전환보다 우선인 안전 문구·공식 지원 경로 | 일반 RAG 답변, 해결 여부 질문으로 지연 |
| 원문 보기 | PDF 페이지와 본문 쪽수, 열기 실패 시 쪽수 안내 | public bucket URL·object key 노출 |
| 상담 이력 | 선택 차량의 질문·상태·답변·근거 | 다른 차량/다른 사용자의 이력 |

## 미결정 항목 — 구현 전 확정 필요

1. 안전 전환 문구, 공식 전화번호/외부 링크, 운영 시간
2. 차량 중복 등록 정책(권장: 같은 모델·연식·모델 구분은 한 대만 등록하고 별칭 수정)
3. 차량 삭제 시 상담 이력의 삭제·비식별 보존 여부
4. 카카오 access/refresh token 만료 시간 및 cookie 저장 방식
5. 고령 사용자를 위한 기본 글자 크기, 대비, 버튼 최소 높이, 오류 안내 문구
