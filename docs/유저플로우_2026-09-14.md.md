# CarMe 차량별 매뉴얼 상담 유저플로우

```mermaid
flowchart TD
  start([앱/웹 진입]) --> loggedIn{로그인 상태?}
  loggedIn -- 아니오 --> login[로그인 화면]
  login --> kakao[카카오 로그인]
  kakao --> authOk{인증·필수 동의 성공?}
  authOk -- 아니오 --> authError[인증 오류/재시도 안내]
  authError --> login
  authOk -- 예 --> home[홈]
  loggedIn -- 예 --> home

  home --> hasVehicle{등록 차량이 있는가?}
  hasVehicle -- 아니오 --> register[차량 등록]
  register --> selectModelYear[모델·연식 선택\n별칭 입력]
  selectModelYear --> manualReady{기본 매뉴얼이 READY인가?}
  manualReady -- 아니오 --> unavailable[현재 상담을 준비 중입니다]
  unavailable --> home
  manualReady -- 예 --> vehicleList[내 차량 목록]
  hasVehicle -- 예 --> vehicleList
  vehicleList --> vehicleDetail[차량 상세\n별칭 수정 또는 삭제]
  vehicleList --> consultHome[상담 시작]

  consultHome --> session[메모리 채팅 세션 생성\n현재 적용 매뉴얼 목록 조회]
  session --> manuals[적용 매뉴얼 표시\nPDF 내려받기 또는 문서 정보]
  manuals --> question[카테고리·세부 증상 선택\n또는 자연어 질문 입력]
  question --> safety{위험 신호인가?}
  safety -- 예 --> safetyEscalation[즉시 안전 안내\n근거 카드 없음·공식 지원 경로]
  safetyEscalation --> continue{계속 질문?}
  safety -- 아니오 --> clarity{정보가 충분한가?}
  clarity -- 아니오 --> clarify[추가 질문 표시]
  clarify --> question
  clarity -- 예 --> retrieve[현재 READY 매뉴얼만\n목차·페이지 검색·재정렬]
  retrieve --> evidence{근거가 충분한가?}
  evidence -- 아니오 --> insufficient[매뉴얼에서 확인하지 못함\n상담 전환 안내]
  insufficient --> continue
  evidence -- 예 --> grounded[근거 기반 답변 생성]
  grounded --> citation[근거 카드\n문서명·PDF 페이지·본문 쪽수·원문 스니펫]
  citation --> source[현재 세션에서\nPDF 다운로드 URL 발급]
  source --> continue
  continue -- 예 --> question
  continue -- 아니오 --> leave[화면 이탈 또는 상담 종료]
  leave --> deleteSession[세션·단기 기억 삭제]
  deleteSession --> home
  session --> expired[TTL/API 재시작으로 세션 만료]
  expired --> newSession[새 상담 시작 안내]
  newSession --> session
```

## 화면·상태 규칙

| 화면/상태 | 반드시 표시할 것 | 금지할 것 |
|---|---|---|
| 차량 등록 | 적재·검수된 모델·연식, 별칭 입력 | 세부 옵션·트림 입력·장착 여부 확정 |
| 빈 채팅 세션 | 적용 매뉴얼 제목, PDF 내려받기, 통합 매뉴얼 고지 | S3 원본 전체의 채팅 적재 |
| `GROUNDED` | 답변, 각 근거 카드, 옵션 미판정 고지 | 인용 없는 행동 지시 |
| `AMBIGUOUS` | 한 번에 하나의 추가 질문 | 근거 없는 조치 |
| `INSUFFICIENT_EVIDENCE` | 확인 불가·상담 전환 | 그럴듯한 원인·해결책 |
| `SAFETY_ESCALATION` | 우선 안전 문구·공식 지원 경로 | RAG 답변, PDF citation, 진단 |
| 원문 보기 | PDF/본문 쪽수, 열기 실패 시 쪽수 안내 | public URL·object key 노출 |
| 세션 종료 | 대화가 저장되지 않음, 새 세션 시작 | 과거 상담 재개·이력 UI |

## 구현 전 확정 필요

1. 안전 전환 문구, 공식 전화번호/외부 링크, 운영 시간
2. 같은 사용자·같은 모델·연식 중복 등록 정책(권장: 1대, 별칭 수정)
3. 카카오 access/refresh token 만료 시간과 cookie/CORS/CSRF 정책
4. 고령 사용자를 위한 글자 크기, 대비, 버튼 높이, 오류 문구
