# CarMe 공식 웹 매뉴얼 동기화 설계

## 목적

현대 디지털 취급 설명서에는 PDF 외에도 인포테인먼트 매뉴얼과 경고등·심볼처럼 웹에서 제공되는 자료가 있다. CarMe는 이 자료를 일반 인터넷 지식으로 섞지 않고, **관리자가 등록한 정확한 차량·연식에 연결된 공식 자료**로만 보조 검색한다.

## 관리자 흐름

1. 차량 카탈로그에 제조사, 차종, 연식을 등록한다.
2. PDF를 업로드하고 `RAG 테스트 준비`으로 `READY` 상태로 만든다.
3. 차량 행의 `공식 웹 매뉴얼 동기화`를 누른다.
4. 시스템은 Tavily로 현대 디지털 취급 설명서의 해당 차량 페이지를 찾는다.
5. 차량 페이지의 메뉴에 표시된 인포테인먼트 종류만 추출하고, 해당 종류의 `ownersmanual.hyundai.com/ivi/.../AVNT/KOR/Korean/` 페이지를 저장한다.

Tavily는 검색 결과를 가져오는 연결 도구일 뿐이다. 최종 저장값은 현대 공식 URL, 제목, 원문 텍스트, 동기화 시각, 해시다. Tavily의 설명문이나 검색 순위는 사용자에게 근거로 보이지 않는다.

## 허용·차단 규칙

| 항목 | 처리 |
| --- | --- |
| `https://ownersmanual.hyundai.com/manual/...`에서 차량명·연식이 일치 | 차량 페이지로 저장 |
| 해당 차량 페이지가 선언한 인포테인먼트 종류 | 상세 웹 매뉴얼 후보로 허용 |
| `.../AVNT/KOR/Korean/...` 국내 한국어 상세 경로 | 저장·검색 허용 |
| 현대 제품 소개, 보도자료, 딜러 페이지 | 차단 |
| 다른 연식·차종, N/하이브리드 등 다른 파생 모델 | 차단 |
| `USA`, `EU` 등 해외 시장 경로 | 차단 |

동기화는 스냅샷이다. 새 결과에 포함되지 않은 예전 공식 웹 출처는 `ARCHIVED`가 되어 사용자 RAG 검색 대상에서 빠진다.

## 사용자 답변 우선순위

1. 차량의 `READY` PDF를 먼저 검색한다.
2. PDF에 직접 절차가 없거나 인포테인먼트 세부 자료로 위임했을 때만 연결된 공식 웹 매뉴얼을 보조 검색한다.
3. 어느 쪽에도 직접 근거가 없으면 모른다고 답한다.
4. 현상 질문은 관련 안내가 있더라도 고장 원인을 단정하지 않고 `CLARIFYING`으로 증상·화면 문구를 추가로 요청한다.

웹 근거를 사용하면 답변 아래에 `현대 공식 웹 매뉴얼` 링크를 표시한다. PDF 근거는 `PDF n쪽`으로 표시한다.
