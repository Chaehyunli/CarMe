# CarMe 개발 일정

> 서비스명: **현대자동차 차량별 매뉴얼 기반 AI 도우미**
> 원칙: 화면·API·DB가 연결되는 작은 수직 흐름부터 완성하고, 매뉴얼 적재와 RAG는 검증 가능한 데이터가 준비된 뒤 붙인다.

## 완료 기준

각 단계는 코드 작성만으로 완료하지 않는다. API 테스트, 정적 검사, 필요한 경우 실제 컨테이너 기동 확인까지 통과해야 다음 단계로 진행한다.

## 1일차 - 데이터 기반과 차량 흐름

- [x] Alembic 초기화 및 PostgreSQL + pgvector 초기 스키마 migration
- [x] 사용자, 토큰, 차량 카탈로그, 내 차량, 매뉴얼/RAG 엔터티와 제약 구현
- [ ] 관리자용 초기 카탈로그 seed와 `ACTIVE` 차량 목록 API
- [ ] 내 차량 등록·목록·별칭 수정·soft delete API 및 소유권 테스트
- [ ] Vue Router·API client 기반과 차량 등록 화면 연결

**당일 완료 기준:** 빈 DB에서 migration을 적용할 수 있고, 활성 카탈로그를 골라 차량을 등록·조회·수정·삭제하는 API 테스트가 통과한다.

## 2일차 - 인증과 매뉴얼 운영

- [ ] 카카오 OAuth callback, access/refresh token, USER/ADMIN 권한 dependency
- [ ] 일반 사용자/관리자 권한 및 타 사용자 리소스 차단 테스트
- [ ] 관리자 카탈로그·매뉴얼 초안·적용 차량 관리 API
- [ ] private MinIO bucket, 제한된 upload/download URL, 파일 해시·PDF 쪽수 검증
- [ ] 관리자 카탈로그·업로드 상태 화면

**당일 완료 기준:** 일반 사용자는 본인 차량만 다루고, 관리자는 매뉴얼 업로드를 요청해 적재 대기 상태까지 전환할 수 있다.

## 3일차 - 매뉴얼 검색과 AI 도우미

- [ ] PDF 텍스트·목차 추출, 페이지 단위 청킹, 임베딩 적재 CLI/worker
- [ ] 차량별 매뉴얼 해석, 목차→청크 검색, 근거 카드 조립
- [ ] 단기 세션·질문 API와 `GROUNDED`/`AMBIGUOUS`/`INSUFFICIENT_EVIDENCE`/`SAFETY_ESCALATION` 처리
- [ ] AI 도우미 화면, 원문 페이지 열기, 세션 종료 UX
- [ ] 평가 질문·권한·인용·모바일 핵심 흐름 회귀 점검

**당일 완료 기준:** 한 차량을 등록해 매뉴얼 근거와 페이지 번호가 포함된 안내를 받고, 근거 부족·위험 상태는 안내 답변과 명확히 구분된다.

## 이번 작업 시작점

현재 작업은 **1일차의 Alembic 초기 스키마**다. migration과 ORM 모델을 먼저 구현한 다음, 차량 API를 그 스키마 위에 추가한다.
